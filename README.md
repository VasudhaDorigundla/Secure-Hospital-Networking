# Secure Hospital Network for Reliable Patient Data Communication

## Project Overview

The Secure Hospital Network is a Java-based computer networking project designed to demonstrate secure, reliable, and efficient communication between different hospital departments.

It implements networking concepts, routing algorithms, data transmission techniques, error detection, encryption, and network performance analysis.

## Technologies Used

- Java
- Cisco Packet Tracer
- Wireshark
- NS-2
- VS Code

## Project Modules

| No. | Module | Description |
|---|---|---|
| 1 | IP Configuration | Hospital department IP addressing and subnet configuration |
| 2 | AES Encryption | Secures patient information using AES encryption |
| 3 | Character Stuffing | Demonstrates character-oriented framing |
| 4 | Bit Stuffing and CRC | Implements bit stuffing and error detection |
| 5 | Sliding Window and Go-Back-N | Demonstrates reliable frame transmission |
| 6 | Dijkstra Algorithm | Finds shortest paths between hospital departments |
| 7 | Distance Vector Routing | Demonstrates distance vector routing |
| 8 | TCP Communication | Reliable patient data transmission using TCP |
| 9 | UDP Communication | Connectionless patient data transmission using UDP |
| 10 | Network Performance Analysis | Analyzes packet delivery, packet loss, and throughput |

## Execution

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal in the project directory.
4. Compile the Java source files.
5. Run the Main class and select a module from the menu.

## Key Features

- Secure patient data communication.
- AES encryption.
- Error detection and reliable transmission.
- Shortest path routing.
- TCP and UDP communication.
- Hospital department network segmentation.
- Network performance analysis.

## Project Purpose

This project demonstrates how computer networking concepts can be applied to a hospital environment to support secure and reliable communication of patient information.
